# Procedural Line-Art Lab
Open `lab/lineart/index.html` directly in Chrome. No build step or dependency. The renderer uses seeded strokes only: candidate marks are scattered inside simple character parts, density creates value, local tangent direction follows form, and a heavier contour preserves the silhouette. Final recommendation: 1550 candidates, length 5.4 px, interior width .87 px, density 1.8, bend .60, jitter 4, boil .15 for calm presentation and 0 for telegraph-critical states. The lab exposes `G.lineart.bake(spec,palette,seed)` and returns a cached horizontal six-frame canvas. Six 64x64 RGBA frames are 98,304 raw bytes, below the 2 MB budget.
