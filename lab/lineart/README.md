# Procedural Line-Art Lab

Open `index.html` in Chrome or another browser. No build step, dependencies, image-generation service or runtime package is required.

The shipping-gate proof is `engine_v3.js`: Wanderer, Strider and Gearling are built from simple data parts and rendered from short coloured strokes. Stroke density creates value; tangent fields follow parts; hard materials receive controlled cross-hatching and contour pooling; cloth keeps more paper visible; region ramps change colour without changing anatomy. The same part-bound stroke grammar is stable through the motion cycles at boil 0.

Controls: character, region palette, density, line boil and seed. Recommended density is 1.0; boil is 0.15 for calm idles and 0 for gameplay-critical poses.

`engine_v2.js` / `coverage.html` hold the Day-2 expansion proof for the remaining enemy/Warden body types. `compare.html` places procedural output beside the project's own painted sheets for internal silhouette/proportion review.

See `CRITIQUE.md` for the 60-pass log. Passes 58 and 59 are the first consecutive all-8-or-better art-direction scores; pass 60 confirms the visual gate.
