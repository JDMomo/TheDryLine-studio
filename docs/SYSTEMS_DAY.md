# First-five-minute teaching beats — 2026-11-22

The teaching loop is intentionally redundant but short. A fresh save encounters the same three facts in four different surfaces before or during the first line:

1. **Station Keeper / Junction arrival:** tokens punch matching fare slots; a punched token is void; the Long Clock borrows attacks from Wardens left active.
2. **Route Board:** shows each Warden's three cut icons and the Terminus borrowed-attacks line before a gate is chosen.
3. **First gate:** names the destination and its slots; the Terminus prompt names what it will borrow.
4. **First Wreck Quay entry / first trunk:** repeats the spend rule in context; the first trunk is drawn from a cut useful against the first Warden.

The goal is recognition, not a tutorial modal: each beat is one or two sentences and never removes control.

## Timetable card decision audit

All ten cards alter a route, resource, boss, grade or token decision rather than a hidden scalar alone.

| Card | Decision changed |
|---|---|
| Rebate Day | Clean-fight routing becomes a token-refund strategy |
| Fare Surge | More scrip, but the kiosk route is closed |
| Short Shift | Straight-to-Terminus risk is reduced by one borrowed attack |
| Late Running | One later line is deliberately denser; route order matters |
| Dry Pipes | Healing moves from standpipes to Warden releases |
| Packed Lunch | Start with another token; early Warden allocation changes |
| Wide Plates | Spend more hits for a larger boss-health punch |
| Stopwatch | Par/Clean grades become immediate health/scrip resources |
| Brittle Stock | One cut is more valuable but wears out after two uses |
| Long Haul | Longer Warden fights pay two health pips, changing order/risk |

Each card already has a railway-notice name and a single plain rule sentence in the UI.
